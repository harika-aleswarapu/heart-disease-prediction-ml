# Heart Disease Prediction System

## Description
This project uses machine learning algorithms to predict the likelihood of heart disease based on patient data. It analyzes various health parameters and provides predictions to assist in early diagnosis.

## Features
- Predicts heart disease risk based on input data
- Compares multiple machine learning algorithms
- Provides accurate and data-driven results

## Algorithms Used
- Logistic Regression
- Decision Tree
- Random Forest

## Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Dataset
- heart.csv dataset used for training and testing

## How to Run
1. Clone the repository:
   git clone https://github.com/harika-aleswarapu/heart-disease-prediction-ml

2. Install dependencies:
   pip install -r requirements.txt

3. Run the project:
   python heart_disease.py

## Results
- Achieved approximately 85% accuracy using Random Forest
